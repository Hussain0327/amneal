## Related clusters (fix together)

- **PsgDocument `appl_no` column** unlocks three: the ingest **collision** (HIGH), the alerts **URL-suffix full-scan** (MED/INV-4), and the **PsgHandler full-scan** pushdown (LOW). One column + migration, three call sites.
- **Surviving concurrent load:** **search_sources isolation** + **uncaught fetch timeout** + **openFDA 429** are one robustness story — centralize a granular timeout + catch + 429 backoff and isolate per-handler. **get_engine lock** + **distinct_metadata cache reorder** are the in-process pair that bite once ingestion runs alongside serving.
- **Orange Book ZIP:** **re-download** + **handler factory rebuild** + **handler-singleton** are the same cache-aside task (Gate-2 task #2).
- **Citation token regex** appears in two slices — fix once with a source-shaped pattern (the uppercase-start idea is wrong).
- **owned-client dedup** overlaps the source-fetch and OB-ZIP work — land the shared contextmanager while there.

## Rejected (false positives — verification refuted these against the real code)

- **sqlite-check-same-thread** — SQLAlchemy's pysqlite dialect already defaults `check_same_thread=False` for file DBs; a 40-thread repro produced 0 errors. The "fix" is a no-op.
- **chroma-nresults-crash** — the pinned chromadb clamps `n_results` to collection count and returns empty arrays on empty/under-sized/no-match corpora; already empty-shaped.
- **orange-book-decode** — `latin-1` is the one codec that cannot raise `UnicodeDecodeError`; corrupt input raises `BadZipFile` earlier. The proposed cp1252 change would *introduce* a crash.
- **chunker-char-split** — no citation pathway substring-matches chunk text (page-keyed citations; BE quotes match raw pages), and the 600-char overlap reproduces boundary content.
- **match-source-page-type** — both sides are int on every real path (`int(meta.get("page"))`, JSON numbers in gold). No falsely-red 0.0.
- **watchlist-ontrue-null** — `on_watchlist: bool` is NOT NULL default True; no insert path omits the flag.
- **update-session-filters-orphan** — `ensure_session` is a get-or-create upsert run before the path; the orphan→IntegrityError is unreachable.
- **init-db-nonatomic** — engine cached via the `_engine` global; run-once single-process startup, no race.
- **resolver-wordlen** — the >=3 filter only relaxes the tie-break; worst case is a safe ambiguous refusal.
- **response-mode-premode** — the pre-resolution value is always rebuilt to the terminal value before every audit write.
- **resolve-brand-timeout** — the openFDA call already carries the 30s `http_timeout_s` via the default client factory.
- **frontend-clarify-stale** — `run()`'s catch already sets `result=null` and render is gated on `!loading`.
